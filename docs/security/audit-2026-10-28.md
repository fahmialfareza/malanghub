# Security audit: 28 Oct 2026

- **Tool:** Cloudflare `security-audit` skill (`.agents/skills/security-audit`), `quick` profile, static source review only.
- **Audited commit:** `d054efac`

This repository is public, so this file lists only what was fixed. Open items and full details are kept in the maintainer's private audit notes.

## Fixed (28 Oct)

- **`ebca97d`, backend:**
  - Account creation is admin-only and ignores privileged fields.
  - `JWT_SECRET` is required (32+ bytes), and tokens must be HS256 with an expiry.
  - Google and Apple sign-in accept only Malanghub's own client IDs and verified emails.
  - Linking an identity provider to a password account clears the password.
  - Only admins approve news.
  - Drafts need login and ownership.
  - Public user objects no longer include email, role or Apple ID.
  - Image upload needs login, and sign-in has rate limits.
  - Deleted users' tokens stop working.
  - 500 responses no longer echo internal errors.
- **`1c6b027`, frontend:**
  - Stored HTML (news, drafts, bios) is sanitized.
  - Social links allow only http(s).
  - JSON-LD, RSS and sitemap output are escaped.
  - Editors send the login token with uploads.
  - Sentry no longer attaches cookies.
- **`d2e2644`, native:** removed the remote dev-server capability and added a CSP.
- **`a9cdf87`:** all local env files are git-ignored.
